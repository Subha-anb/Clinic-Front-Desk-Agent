How it stays safe

Three layers check every message

LAYER 1

Rules

Instant checks for emergencies, medicines, doses, symptoms, test results and privacy. Catches tricks like “p@racetam0l”.

LAYER 2

Claude classifier

Catches reworded and other-language questions. It can only make a verdict stricter, never looser.

LAYER 3

Output guard

Checks every reply Claude writes. Blocks doses, advice and personal data before anything is sent.

Emergencies get a fixed 112 / 108 reply at once. Clinical questions get a fixed reply and a staff ticket. Claude never writes those replies.

Defence in depth. The rules are fast and predictable; the Claude classifier catches what rules miss but cannot overrule them; the output guard is a last check on anything Claude writes. Wording for emergencies and escalations is fixed, so it cannot drift.
